
# CS 3354 Team 6 — BookBridge

## Project
BookBridge is a campus textbook exchange system for UTD students. It allows students to list used textbooks, search for books they need, reserve books, and pay through a third-party payment service. Buyers and sellers arrange to meet on campus to exchange the books.

## Conventions
Team members should use separate branches for their work and submit pull requests for review before merging into main. GitHub issues are used to track tasks and individual contributions.

The team discusses decisions together and uses a majority vote when agreement cannot be reached. The project manager breaks ties.
